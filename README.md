# diff2png

`git diff` から必要な変更箇所だけを選び、コードレビューや検証記録に使える PNG を作成するローカル Web アプリです。

- 作業ツリー、ステージ済み、1コミット、2コミット間の差分を解析できます。
- 変更のまとまり（hunk）をプレビューし、出力範囲やハイライトを整えられます。
- 必要な hunk だけを選び、読みやすい差分画像としてまとめて出力できます。

## はじめる

### 必要なもの

- Git
- [uv](https://docs.astral.sh/uv/)
- Python 3.12 以上

### インストール

```bash
git clone https://github.com/senu3/diff2png.git
cd diff2png
uv sync --locked
uv run playwright install chromium
```

### 起動

```bash
uv run python app.py
```

ブラウザが自動的に開きます。開かない場合は、ターミナルに表示された URL をブラウザで開いてください。通常は `http://127.0.0.1:5127` です。

### 最初の PNG を出力する

この手順では、初期設定の **作業ツリー** の差分を使います。対象の Git リポジトリに、コミット前の変更を1つ以上用意してください。

1. **参照** を選び、対象リポジトリのフォルダを選択します。解析が終わると、左側の **Hunks** に変更箇所が表示されます。
2. **Hunks** から変更箇所を選び、右側の **Preview** で内容を確認します。最初の解析では、検出された hunk がすべて出力対象として選択されています。
3. 出力しない hunk のチェックを外します。
4. **選択を出力** を選びます。

出力が完了すると、選択した hunk ごとに PNG が生成されます。初期の保存先は、このアプリの `diff_screenshots/` フォルダです。

## 主な操作

- **差分の取得元**: 作業ツリー、ステージ済み、1コミット、2点比較を切り替えます。
- **ファイルフィルタ**: 特定のファイルに含まれる hunk だけを表示・出力します。
- **Preview**: 通常、パッチ、削除の表示を切り替え、行内差分や出力範囲を調整します。
- **表示設定**: コンテキスト行数、近接 hunk の統合、PNG の横幅、背景を変更します。
- **保存先**: 出力先を相対パスまたは絶対パスで指定し、フォルダを開いたり、diff2png が生成した PNG を削除したりできます。

表示設定、保存先、前回使用したリポジトリ、ファイルフィルタはブラウザに保存され、次回起動時に引き継がれます。

## 差分の取得元

| 取得元 | 対象 |
| --- | --- |
| 作業ツリー | `HEAD` と現在の作業ツリーの差分 |
| ステージ済み | Git のインデックスに追加済みの差分 |
| 1コミット | 選択したコミットで加えられた差分 |
| 2点比較 | 選択した比較元と比較先のコミット間の差分 |

リポジトリを解析した後、**差分の取得元** を開いて切り替えます。1コミットと2点比較では、リポジトリのコミット一覧から対象を選択できます。

## 出力設定

初期設定では、PNG は幅 `960 px`、通常背景、前後 `5` 行のコンテキストで生成され、`8` 行以内にある近接 hunk は1枚にまとめられます。画面右上の **表示設定** から変更できます。

保存先は **保存先** から変更できます。相対パスはこのアプリのフォルダを基準に解決され、絶対パスも指定できます。

## 困ったとき

### ブラウザが自動的に開かない

ターミナルに表示された `起動しました → ...` の URL をブラウザで開いてください。

### Chromium が見つからず PNG を出力できない

次のコマンドを実行してから、アプリを再起動してください。

```bash
uv run playwright install chromium
```

### ポート 5127 が使用中

アプリは `5127` 以降の空いているポートを自動的に使用します。実際の URL はターミナルで確認できます。

探索を始めるポートを指定する場合は、起動前に `DIFF2PNG_PORT` を設定します。

PowerShell:

```powershell
$env:DIFF2PNG_PORT = "5200"
uv run python app.py
```

macOS / Linux:

```bash
DIFF2PNG_PORT=5200 uv run python app.py
```

### 差分が表示されない

選択した **差分の取得元** に変更があるか、対象として正しい Git リポジトリを選んでいるかを確認してください。

## データの扱い

アプリは `127.0.0.1` で起動し、選択したリポジトリをローカルで解析します。生成した PNG も指定したローカルフォルダに保存されます。
