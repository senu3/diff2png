# diff2png

`git diff` から必要な変更箇所だけを選び、コードレビューや検証記録に使える PNG を作成するローカル Web アプリです。

- 未ステージ、ステージ済み、コミット履歴から連続した変更範囲をまとめて解析できます。
- 変更のまとまり（hunk）をプレビューし、出力範囲やハイライトを整えられます。
- 必要な hunk だけを選び、読みやすい差分画像としてまとめて出力できます。

## はじめる

### 必要なもの

- Git
- [uv](https://docs.astral.sh/uv/)
- Python 3.12 以上

### インストール

```bash
git clone https://github.com/senu3/diff2png.git
cd diff2png
uv sync --locked
uv run playwright install chromium
```

### 起動

```bash
uv run python app.py
```

ブラウザが自動的に開きます。開かない場合は、ターミナルに表示された URL をブラウザで開いてください。通常は `http://127.0.0.1:5127` です。

### 最初の PNG を出力する

この手順では、未ステージ・ステージ済みの変更がない Git リポジトリから、直近コミットの差分を出力します。対象リポジトリにコミットが1件以上あることを確認してください。

1. **参照** を選び、対象リポジトリのフォルダを選択します。現在の変更がないため、**差分の取得元** が開き、直近コミットが選択されます。
2. **選択範囲を解析** を選びます。左側の **Hunks** に変更箇所が表示され、右側の **Preview** に最初の hunk が表示されます。
3. **Hunks** と **Preview** で内容を確認します。検出された hunk はすべて出力対象として選択されています。
4. 出力しない hunk のチェックを外します。
5. **選択を出力** を選びます。

出力が完了すると、選択した hunk ごとに PNG が生成されます。初期の保存先は、このアプリの `diff_screenshots/` フォルダです。

## 主な操作

- **差分の取得元**: 未ステージ、ステージ済み、コミット履歴から連続した変更範囲を選択します。
- **ファイルフィルタ**: 特定のファイルに含まれる hunk だけを表示・出力します。
- **Preview**: 通常、パッチ、削除の表示を切り替え、行内差分や出力範囲を調整します。
- **表示設定**: コンテキスト行数、近接 hunk の統合、PNG の横幅、背景を変更します。
- **保存先**: 出力先を相対パスまたは絶対パスで指定し、フォルダを開いたり、diff2png が生成した PNG を削除したりできます。

表示設定、保存先、前回使用したリポジトリ、ファイルフィルタはブラウザに保存され、次回起動時に引き継がれます。

## 差分の取得元

初期状態では **未ステージ** と **ステージ済み** が選択され、`HEAD` から現在の作業ツリーまでの変更をまとめて解析します。

現在の変更がない場合は **差分の取得元** が自動的に開き、直近コミットが選択されます。**選択範囲を解析** を選ぶと、そのコミットの変更を表示できます。

**差分の取得元** では、未ステージ、ステージ済み、コミット履歴を同じ時系列リストから複数選択できます。離れた項目を選択すると間の変更も選択範囲へ含まれ、範囲全体を1つの差分として解析します。

選択範囲の右側にあるボタンから、読み込まれた差分ソースをすべて選択またはすべて解除できます。すべて解除した状態では解析できません。

| 選択範囲 | 対象 |
| --- | --- |
| 未ステージ | Git インデックスと現在の作業ツリーの差分 |
| ステージ済み | `HEAD` とGitインデックスの差分 |
| 未ステージ + ステージ済み | `HEAD` と現在の作業ツリーの差分 |
| 複数コミット | 最古の選択コミットの親から最新の選択コミットまでの差分 |
| コミット + 現在の変更 | 最古の選択コミットの親からインデックスまたは作業ツリーまでの差分 |

解析結果は取得元ごとに分割せず、選択範囲の最終的な差分としてhunkへ統合されます。ファイル単位の絞り込みは**ファイルフィルタ**から行います。

## ファイルフィルタ

解析された変更ファイルはディレクトリ単位のツリーで表示されます。ファイルまたはフォルダーを選択すると、その範囲に含まれるhunkだけへ絞り込めます。検索中は一致したファイルと親フォルダーが自動的に展開されます。

初期状態ではすべてのファイルが選択されています。選択バーの **すべて選択** と **すべて解除** で対象をまとめて変更できます。すべて解除した状態では適用できません。

## 出力設定

初期設定では、PNG は幅 `960 px`、通常背景、前後 `5` 行のコンテキストで生成され、`8` 行以内にある近接 hunk は1枚にまとめられます。画面右上の **表示設定** から変更できます。

保存先は **保存先** から変更できます。相対パスはこのアプリのフォルダを基準に解決され、絶対パスも指定できます。

## 困ったとき

### ブラウザが自動的に開かない

ターミナルに表示された `起動しました → ...` の URL をブラウザで開いてください。

### Chromium が見つからず PNG を出力できない

次のコマンドを実行してから、アプリを再起動してください。

```bash
uv run playwright install chromium
```

### ポート 5127 が使用中

アプリは `5127` 以降の空いているポートを自動的に使用します。実際の URL はターミナルで確認できます。

探索を始めるポートを指定する場合は、起動前に `DIFF2PNG_PORT` を設定します。

PowerShell:

```powershell
$env:DIFF2PNG_PORT = "5200"
uv run python app.py
```

macOS / Linux:

```bash
DIFF2PNG_PORT=5200 uv run python app.py
```

### 差分が表示されない

**差分の取得元** に表示された範囲を確認し、変更を含む項目を選んで **選択範囲を解析** を実行してください。現在の変更がなく、コミット履歴もないリポジトリでは差分を表示できません。

## データの扱い

アプリは `127.0.0.1` で起動し、選択したリポジトリをローカルで解析します。生成した PNG も指定したローカルフォルダに保存されます。
